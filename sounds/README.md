# Sounds

Make one folder per profile and name each file after its event:
`SessionStart`, `UserPromptSubmit`, `Notification`, `PermissionRequest`,
`SubagentStop`, `Stop` or `SessionEnd`, with any audio extension.
For example `default/Stop.wav` or `boom/PermissionRequest.mp3`.

`default` is the fallback for any event a profile doesn't have.
